MCP 連線設定

把 Paper Lab 接到 claude.ai 的對話框（手機 / 桌面都行）。 連上後，直接跟 AI 說「我想研究 X」，它會用引導式提問帶你發想題目、界定 research gap、產出一份可執行的研究計畫提案。

MCP 連線是會員功能。用 Google 登入後即可申請連線 Token。

尚無 MCP 權限

③ 確認連上

儲存後，Connectors 清單會出現「Paper Lab」並顯示 Connected。看到了就代表連線成功。

④ 新對話開始發想

新開一個對話，點輸入框旁的工具，確認 Paper Lab 有掛上，直接說「我想研究 …」就會進入 5 步引導式發想。

claude.ai / 對話
+ 工具：Paper Lab ✓
我想研究 高齡者穿戴裝置健康監測的成效

設定成功的判斷

  • Connectors 清單看到 Paper Lab 顯示 Connected。
  • 說「我想研究 X」時，AI 會先呼叫 start_brainstorm 帶你跑 5 步，而不是直接丟題目。
  • 工具清單看得到 search_literature / propose_proposal 等。

最常卡住的地方

  • 找不到 Connectors：用桌面/手機網頁版 claude.ai（免費帳號限 1 個 custom connector）。
  • URL 要貼整段含 ?token=，不要拆開；OAuth 欄位留空。
  • Token 重新整理後看不到完整網址：撤銷後重發一個即可。
