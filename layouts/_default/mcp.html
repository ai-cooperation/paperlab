把 Paper Lab 接到 ChatGPT 應用程式（也支援 claude.ai 等 MCP 工具）。 連上後，直接跟 AI 說「我想研究 X」，它會用引導式提問帶你發想題目、界定 research gap、產出一份可執行的研究計畫提案。

③ 回對話選 Paper Lab，開始發想

開新對話或回既有對話，點輸入框旁的 加號，選「Paper Lab」。看到工具掛上後，直接說「我想研究 …」就會進入 5 步引導式發想。

ChatGPT / 對話
+ 工具：Paper Lab ✓
我想研究 高齡者穿戴裝置健康監測的成效

設定成功的判斷

  • 對話框加號選單看得到 Paper Lab。
  • 說「我想研究 X」時，AI 會先呼叫 start_brainstorm 帶你跑 5 步，而不是直接丟題目。
  • 工具清單看得到 search_literature / propose_proposal 等。

最常卡住的地方

  • 用手機 App / 桌面 App 找設定：請改用 ChatGPT 網頁版。
  • 沒看到「應用程式 / 開發者模式」：先在進階設定打開開發者模式。
  • 驗證選成 OAuth：請改「無驗證」，token 已在 URL；URL 要貼整段含 ?token=。

用 claude.ai？流程一樣 —— Settings → Connectors → Add custom connector，把同一段 URL 貼到 Remote MCP server URL，OAuth 留空即可。
